# 3. CONSOLIDATED FINDINGS (ruthless)

## What consistently worked
1. Strong start + map + “Where first?” — no paralysis for motivated tables  
2. Longarm joy beat after Olive — pacing valve  
3. Three Clue Rule under split — both halves reached “numbered contracts unfinished”  
4. Split 5-min cuts + ripples at *top* of next scene  
5. T-30 Betrayal cut (Olive → Teddy) — maximum dread, minimum words  
6. Fail-forward when ritual pieces missing — session survived  

## What consistently broke
1. **Teddy breadcrumb systems are independent and stack** (Olive drawing + black iron hum + marionette track + thread cramp)  
2. **Ritual claim/habit strands assume unvisited nodes** (church, crank) — Three Clue Rule not applied to ritual fuel  
3. **Olive silent scene has no job for non-social PCs**  
4. **Hell-poster deal under-prepped** for impulsive PCs  
5. **Countdown/Ledger tick rules too judgment-heavy** — GMs drift  
6. **Ignoring Olive must create new playable situation**, not a scolding

# 4. MANDATORY PATCHES (implement now)

## PATCH T1 — Teddy Breadcrumb Budget
**Rule:** Visible counter on DM screen: **Teddy crumbs 0/2**.  
Any source that would fire a tell checks the counter first. At 2, **suppress all further Teddy tells this session**, even if conditions match.  
**Portable fallback:** If Teddy never visits a flagged node, Ledger tick may spend *one* budgeted crumb as a private wrist-click (location-agnostic).  
**Do not** fire Olive-drawing-toward-Teddy AND black-iron-hum AND marionettes in the same hour.

## PATCH T2 — Ritual Fuel Redundancy
Ritual strands always have a **fallback at reduced strength**:

| Strand | Ideal source | Fallback (always available) | Cost of fallback |
|--------|--------------|-----------------------------|------------------|
| Claim | Contract tag / letter / guestbook | Cobb admits he kept a scrap tag from Olive's window | Caps outcome at Partial unless a second claim source found |
| Memory | Stone + objects around town | Purdy tells one true memory of Olive laughing | Same |
| Habit | Music box crank / demonstrated choice | PC asks Olive permission + she offers ribbon (cottage beat 8) | Same |

Skipping church/crank **no longer soft-locks** the ritual — it lowers the ceiling.

## PATCH T3 — Olive Scene Jobs (non-social PCs)
Sidebar for cottage:
> While Quiet Game runs, assign idle PCs:  
> (a) watch curtain across the lane,  
> (b) check window latch / footprints,  
> (c) stand door guard and hear street rumor.  
Hard soft-cap: **~15 minutes** or 3 Quiet Game questions (not 5). At minute 12: “Olive’s getting tired.”

## PATCH T4 — Olive Competence Framing
From disability-RP research: Olive is clever, stubborn, purposeful — **not a tragedy prop**. Strings are the problem; she is not “broken.” Prefer agency beats (she tests them, she draws, she chooses) over pity narration.

## PATCH T5 — Collector’s Bargain Micro-Script
When a PC addresses a hell poster / courteous repatriation notice:

1. **Poster:** “Inquire within the quiet. State your consideration precisely. Vague offers void the contract.”  
2. **Weight table:**  
   - Vague/bluff → void, no tick  
   - Small (coin, favor, minor secret) → thread hair-thin, Ledger +0 or +1  
   - Heavy (years of life, true name, another’s fate) → visible thread prop, Ledger +1, minor manifestation  
3. **Trusted NPC interrupt (once):** Halloway/Roke/Purdy may physically confiscate poster — converts impulse into a choice.  
4. **Rescission window:** Before next eleventh bell, they may annotate/void with help (Cobb/Ambrose) — soft clock, not gotcha.  
5. **Physical prop:** Hand a black thread/bracelet if deal binds.

## PATCH T6 — Ledger Tick Hygiene
Tick Ledger **only** when:
- (a) physical Contract tag found, OR  
- (b) “Mr. Strings” / “Ashur Vail” spoken aloud, OR  
- (c) public ritual/spectacle / bound hell-deal  

**Do not** tick for generic Hell rumors (those are Panic/flavor).

## PATCH T7 — Olive Clock = Transform, Don’t Punish
When Olive clock fills:
- **Not:** “You failed, Cobb botches, feel bad.”  
- **Yes:** Crisis arrives *into their current activity* using assets they already earned.  
  - If in tavern: Olive appears at the door / Pip: she’s walking to church — tavern contacts become escort allies.  
  - If forging: Bram’s finished blade rings; he insists they go *now*.  
  - Path B finding: countdown’s final tick must create a **new playable situation**, not scold avoidance.

## PATCH T8 — Countdown Hard Cue
Every **Breath** after a Score, OR every **45 real minutes**, glance at MotW countdown.  
Do not rely on raw memory during split scenes.  
**Ripple ledger card:** one line per A→B ripple; cross off when delivered.

## PATCH T9 — Split Cut Exception
Allow **one** protected cut per split segment: if an emotional beat is ≥80% done and within ~30 seconds of landing, let it land, then cut.

## PATCH T10 — Halloway Hard-No Consolation
If PC pushes Neri’s release with conviction but no evidence:  
> “He’s not innocent of everything. He’s innocent of *this*.”  
Keeps protectiveness fed; release still blocked.

## PATCH T11 — Three Roads Mid-Session
At first stall or ~1:40, restate **exactly three** options with cost tags:
1. Olive/Cobb — emotional, ~45–60 if ritual  
2. Murder tags (Watch/church/mortuary) — political heat  
3. Promise/town (Bram/tavern) — lower heat, bonding  

## PATCH T12 — Heart-First Recommended Spine
For tables that self-select Olive early:  
**Beach → Olive (~15) → Cobb (Longarm valve) → Bram (promise + iron) → Breath tavern → ONE detour (Watch XOR Whistlecraft) → ritual.**  
Don’t require both detours.

# 5. UPDATED DM SCREEN (post-playtest)

```
LOOP: Strong start → Map+rumors → Where next? → Node → wander → interrupt?

TEDDY CRUMBS: ☐☐ (max 2 — then SUPPRESS)
LEDGER tick only: tag / name spoken / spectacle|deal
OLIVE clock full → TRANSFORM their current scene into crisis (use their allies)
EVERY BREATH or 45m → check MotW countdown
OLIVE SCENE: jobs for idle PCs; 15m or 3 questions; “getting tired” at 12
HELL POSTER: precise consideration; weight table; NPC confiscate once; rescission window
STALL >5m debate → Three Roads (exactly 3) or Pip
RITUAL: fallbacks always exist; missing church/crank = Partial ceiling
T-30: cut mid-tension; stop talking
```

# 6. PATH NOTES FOR THE REAL TABLE

**If they go heart-first (most likely after Olive’s story):** use PATCH T12 spine; keep Whistlecraft OR Watch as optional upgrade.

**If they tavern-first:** lean into games; let Olive clock advance quietly; when it bites, Pip brings Olive-crisis *into the tavern* so Rex/Nyx’s social capital matters.

**If they split:** ripple card + verbal clock echo + one protected emotional cut; pre-pick which countdown step is the reunion trigger (Shadows marionette decoy worked well).

**If someone deals with Hell:** run PATCH T5 script; hand a thread prop; don’t improvise law from scratch mid-split.
